## What this means for the project

**Confirmed consequence: no GPU benchmark can be executed on this machine.** Any
number claiming otherwise would be fabricated, which CLAUDE.md §0 forbids.

What *can* be developed and genuinely verified here:

- the full framework, schema, CLI and comparison mathematics;
- the compute-capability and precision matrix (pure logic, unit-tested against
  documented capabilities of real GPUs);
- every failure and degradation path — this machine is an excellent test fixture
  for "no driver present", which is otherwise awkward to simulate;
- CPU-execution-provider paths for ONNX Runtime and PyTorch, useful for validating
  that the harness mechanics work, but **not** as performance data.

What requires different hardware:

- any CUDA, TensorRT or TensorRT-LLM measurement;
- NVML telemetry (utilisation, power, temperature, clocks);
- engine build behaviour and precision comparisons.

Per the project plan, real benchmarks will be run on a cloud NVIDIA GPU. The
framework is therefore built to be portable and to refuse, loudly, to produce
numbers it cannot measure.
